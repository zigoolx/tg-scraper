من عذرخواهی می‌کنم از همگی. حق با شما بود. متاسفانه درست بود و الان برای من هم پولی شدن مدل‌های Mimo روی Nara:) گویا سایتشون باگ داشت فعلا از Open router + Nvidia nemotron استفاده می‌کنیم
رفقا این هم فراموش کرده بودم بهتون بگم
یه راه دیگه‌ی رایگان برای استفاده‌ی بدون هزینه از MiMo، نصب opencode هست که تمام این مدلها رو رایگان داره درونشون. با 9router هم میتونید از مدلهای opencode برای هرمس استفاده کنید. همونطور که توی ویدئوی 9router نشون دادم.

برای نصبش هم از این دستور استفاده کنید:
npm i -g opencode-ai

روی سرور اوبونتو هم از

sudo apt update
sudo apt install snapd -y
sudo snap install opencode --classic

برای نصب کردن 9Router روی سرور اوبونتو اول sudo apt update && sudo apt upgrade -y curl -fsSL https://get.docker.com | sh sudo systemctl enable --now docker و بعدش این دستور رو بزنید docker run -d \ --name 9router \ -p 20128:20128 \ -v "$HOME/.9router:/app/data"…
اگر خواستید 9router رو روی سرور آپدیت کنید:

docker pull decolua/9router:latest

docker rm -f 9router

docker run -d \
  --name 9router \
  -p 20128:20128 \
  -v "$HOME/.9router:/app/data" \
  -e DATA_DIR=/app/data \
  -e JWT_SECRET="change-this-to-a-long-random-secret" \
  -e INITIAL_PASSWORD="your-strong-dashboard-password" \
  decolua/9router:latest
